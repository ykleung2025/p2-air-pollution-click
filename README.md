# 空氣污染點擊遊戲（DeepSeek 版）

小二環保小教室：60 秒內，把飄出來的「污染行為」點出來。

## 玩法

- 飄動卡一出現就有 **圖示（emoji）＋名稱**，適合平板觸控。
- **點到污染行為**得 **1 分**，並顯示對空氣、動物、植物或人的危害提示。污染卡包括：工廠排煙、廢氣排放、火力發電、提煉石油、金屬冶煉、揮發溶劑、過度開車、車輛怠速、遺撒渣土、焚燒垃圾、露天焚燒、露天燒烤、燃煤取暖、燃放煙花、焚香燒紙、餐飲油煙、建築揚塵、拆卸建築、噴灑農藥、砍伐樹木、堆肥發酵。
- **點到淨化行為**（種植樹木、騎單車、搭公車）扣 **1 分**（分數不會低過 0），並顯示它怎樣令空氣變好。
- 60 秒結束後顯示得分、評語，以及污染／淨化行為的結算複習。
- 可以按「再玩一次」重新開始。
